        Laravel setup guide — from a clean Ubuntu server to a deployed app

        Bare-metal Nginx/PHP/MySQL, the Docker equivalent, and an EC2 + RDS deploy guide, all in one place. This page reads directly from your .md files each time it polls — edit and save any of them, and this view updates on its own within a couple seconds.

        ⚠ Can't reach the source files over fetch(). This page needs to be served over http://, not opened as a file:// path — see the note at the bottom of the page.
        Reads live from nginx-laravel-setup/laravel-nginx-setup.md, support/envsample.md, everything under docker-setup/, phpscript.md, and ubontoscirpt.md in this folder.

        Browsers block a plain double-clicked HTML file from reading its neighbors, so this needs a tiny local server. From this folder run:
        python3 -m http.server 8000
        then open http://localhost:8000/guide.html. Leave that command running — this page keeps polling the files as long as the server is up.
